# Rent-Calculator
A simple Python program to calculate the amount each person has to pay

for rent, food, and electricity expenses.

## Features

- Calculates electricity bill

- Adds rent and food expenses

- Divides the total bill among people

- Shows the amount each person has to pay

## Requirements

- Python 3.x

## How to Run

Run the following command:
python rent_calculator.py

## Inputs

The program asks the user for:

- Total rent

- Total food expense

- Electricity units used

- Electricity charge per unit

- Number of people


## How It Works

Electricity Bill = Electricity Units × Charge Per Unit


Total Bill = Rent + Food + Electricity Bill


Amount Per Person = Total Bill ÷ Number of People

## Example

Rent = 10000

Food = 2000

Electricity Units = 100

Charge Per Unit = 8

People = 4



Electricity Bill = 100 × 8 = 800



Total Bill = 10000 + 2000 + 800

           = 12800



Each Person Pays = 12800 ÷ 4

                = 3200



## Output

Each person will pay = 3200
